# 千岛湖渔业溯源系统 V1.1.5

本仓库独立保存 V1.1.5 交互原型，与其他原型仓库分开发布。

## 功能

- 主数据管理：摄像头管理、养殖池信息维护。
- 摄像头管理：查看已接入设备、在线状态和关联养殖池，管理页独立查看直播。
- 养殖池：按现有界面提供列表、新增和编辑弹窗，可单选、更换或解除摄像头关联。
- 关联规则：一台摄像头可关联多个养殖池，一个养殖池最多关联一台摄像头。
- 驾驶舱：数据总览与视频监控在内容区右上角切换；设备信息仅在视频页展示。
- 视频监控：固定九宫格，仅按基地、设备状态筛选，支持分页和点击画面全屏展开。

## 使用

打开在线预览，或下载后用浏览器打开 `index.html`，无需安装依赖。

这是交互原型：设备数据和画面用于展示，未连接真实摄像头与后端。新增、编辑和关联数据保存在当前浏览器，线上正式实现需对接后端接口。

## 发布边界

本次发布只操作本仓库，不更新其他仓库的分支、标签、文件或 Pages 配置。
